## eval

| скрипт | що робить |
| --- | --- |
| `formal_eval.py` | рахує RSS на затверджених наборах і час у контейнері, друкує рядок для Formal Results |
| `compare.py` | парне порівняння кількох агентів з однією базою |
| `diag.py` | де агент програє фізично: витрати, скинуте навантаження, партії, продані чипи |
| `balance.py` | баланс чипів по етапах: фабрика, завод, ринок |
| `routes.py` | мережа: енергосистеми, фабрики, ринки, усі слоти дії з маршрутами |
| `sets.py` | затверджені набори епізодів |
| `records/` | вартості моделей із Formal Results по епізодах, для парних порівнянь без повторного прогону |

Усі запускаються з кореня репозиторію: `uv run python hub/eval/<скрипт>.py --help`.

## Відкриті питання

- `mpc` несе в zip копію модулів shockbench-flow (ліцензія MIT). Правила дозволяють будь-які файли поруч з
  `agent.py` і забороняють лише сторонні імпорти, але перед сабмітом такої моделі варто запитати організаторів.
- Чи збігається локальний RSS із балом борду: з'ясує перший сабміт.
- Чому LP-планувальник на Full дає 0.42 проти 0.69 на Small.
- Дедлайни змагання: вписати зі сторінки змагання.
