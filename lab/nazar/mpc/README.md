# lab/nazar/mpc: діагностика (read-only)

Скрипти розбору агентів на одних і тих самих епізодах; усі беруть `play` з `lab/anastasiia/heur_lab2/tools/account.py`
(записи симулятора по тижнях: що запитано, що виконано, склад, партії, списання). Результати й висновки — у
`hub/tried/mpc.md` («LP у гібриді…») і `hub/tried/heuristics.md` («Де правила і гібрид слабкі…»). Огляд теки —
`../README.md`.

| скрипт | питання |
| --- | --- |
| `wafer_diag.py`, `wafer_trace.py` | куди йдуть пластини: запит, виконано, склад на фабриках, прихід, списання |
| `osat_diag.py`, `osat_time.py`, `osat_eps.py` | чому упаковані чипи застрягають на заводах: за заводами, у часі, по епізодах |
| `doomed.py` | які фабрики випускають чипи, що не мають виходу |
| `raw_diff.py`, `raw_clip.py` | де LP везе сирі чипи інакше за правила; чи обрізає симулятор запити правил |
| `free_lost.py` | коли система втрачає вільну генерацію |
| `fuel_trace.py` | паливо на шляху до однієї системи по тижнях: запит, виконано, протоки, запаси |
| `worst.py` | бал за рівнями шкоди й найгірші епізоди |
| `full_run.py` | довгий прогін (наприклад 400 епізодів Full) партіями з прогресом і `--resume` |

Пастка: сума запитів по всіх слотах пластин рахує багатоходові маршрути на кожній ділянці й для порівняння агентів не
годиться (див. `mpc.md`); міряти приход на фабрики й партії.
