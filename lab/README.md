# lab: особисті теки

У кожного своя тека: `lab/<ім'я>/`. Це вільна зона для коду експериментів, нотаток і проміжних агентів.

- Пишемо лише у свою теку. Комітимо прямо в main, без рев'ю.
- Агента з особистої теки оцінюємо за шляхом: `uv run sbf evaluate lab/<ім'я>/agents/<агент> --task=small`.
- Важкі файли прогонів ідуть в `outputs/` (поза git), а не сюди.
- Після кожного експерименту — рядок у `hub/tried/<підхід>.md`, навіть якщо не допомогло.
- Модель, яка заслуговує на Formal Results, переїжджає в `agents/<хто>_<підхід>_<деталі>/` разом із рядком у
  `hub/FORMAL_RESULTS.md`.
